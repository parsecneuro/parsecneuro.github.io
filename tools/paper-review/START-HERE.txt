PAPER REVIEW 1.0.0-alpha.1 (ALPHA 1)

OPEN THE APP
On your website: Tools > Paper Review.
On Windows: extract the ZIP, then double-click start_local.bat in this folder.
On macOS/Linux: open a terminal here and run python3 start_local.py.
Python 3 is needed only for local preview. Keep the terminal open while using
http://127.0.0.1:8765/index.html. Press Ctrl+C in the terminal to stop.
Keep the same website/local address and browser to restore saved reviews.

READ AND COMMENT
Open your PDF. Both views scroll and zoom independently. Drag the dividers
to adjust their sizes. The header, icons, and page margins are more compact.
A notebook comment records the left-hand PDF page where you began typing.
View all comments opens the editable review. Export .txt downloads saved
comments plus any unfinished notebook draft, without automatic page markers.

ANNOTATE
Each PDF has a small toolbar: Select, Highlight, Note, Circle/Ellipse,
Rectangle, Erase, Color, and Undo. Hover over an icon to see its name.
Highlight: drag across text. On a scanned page, drag a highlight rectangle.
Note: click the desired location, write your note, and save it.
Circle/Rectangle: drag around the area you want to mark with your mouse/pen.
Select: click an existing mark to edit its note or color, or delete it.
Erase: click a mark to remove it. Undo restores the last annotation change.
Marks appear in both views and are saved locally with the current PDF.
Notebook comments and notes attached to PDF marks are separate.

EXPORT AND REMOVE
The buttons below the main notebook give you all file actions.
Export .txt downloads the notebook review. Export PDF creates a separate
PDF with native annotations. Other PDF
viewers can show the marks and open their attached notes. The original file
is unchanged. Export of password-protected PDFs is not supported.
The red Remove PDF & notes button closes the current paper and deletes its
saved notebook comments, draft, PDF annotations, and extracted references
from this browser after confirmation. It does not delete your original PDF.
Export any copies you need before removing the review.

REFERENCES
Select the bibliography pages in References and extract the list locally.
Method: Improved uses local citation-pattern rules. Original (v0.1) restores
the first version's extraction and can be used whenever that works better.
Citation style: Detect automatically, Author-year (APA/Harvard patterns), or
Numbered (IEEE/Vancouver patterns). Style hints affect how entries split;
they do not rewrite references or verify them against an online database.
Page layout: Detect automatically, One column, or Two columns. Choose the
matching layout when a PDF's text order is unusual.
Remove manuscript line numbers is OFF initially. Turn it on only when line
numbers enter the extracted bibliography. Ambiguous numbers are preserved.
The Original method uses the old automatic layout and ignores new settings.
Check entries against the PDF and use the editable bibliography field to
correct remaining mistakes. Local English OCR is available for scans.
Optional Google links send only the selected citation when you open one.

LOCAL SAVING
PDFs are read in browser memory and are not uploaded or stored by the app.
Comments, annotations, and extracted references are saved in this browser.
Reopen the same PDF to restore them. If saving is blocked, reviews remain
in this tab until it closes; reopen affected PDFs and export your work.
Clearing browser data, private browsing, or changing the website address
can make saved reviews unavailable. Export copies when finished.
TXT export contains only notebook comments. Use Export PDF for marks.
Privacy & help contains instructions and privacy information only.

All PDF, annotation, and OCR processing uses bundled local files. The app
has no AI review service, manuscript upload, or automatic search.
When the website counter is enabled, app openings send only the app ID
and a random request ID to the counter service. PDFs, filenames, notes,
annotations, and references stay local. Local previews do not count.
