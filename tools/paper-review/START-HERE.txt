PAPER REVIEW 1.3.0 — SEARCH AND APPEARANCE

OPEN THE WEBSITE
Use Tools > Paper Review on your published website:
https://parsecneuro.github.io/tools/paper-review/
No Python, BAT file, Git installation, or terminal command is needed to use
the published app. Opening a downloaded index.html file directly is different
from opening the website. Keep the bundled vendor files on GitHub Pages.

UPDATE YOUR WEBSITE
Unzip paper-review.zip. In your GitHub repository, open tools/ and use
Add file > Upload files to upload the extracted paper-review folder.
For an existing installation, only these files changed or were added:
  index.html, version.json, START-HERE.txt
  css/app.css
  js/app.mjs, js/viewer.mjs, js/viewer.css, js/workspace-ui.mjs
  js/appearance.mjs, js/pdf-search.mjs
Upload each file into its matching folder in GitHub and commit the changes.
The included vendor folder is unchanged and does not need re-uploading.
Keep the folder at
tools/paper-review/ (do not create a second nested paper-review folder).
This update includes two new JavaScript modules: appearance.mjs and
pdf-search.mjs. Upload those too. Wait for GitHub Pages to finish publishing,
then refresh the app with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
Your existing counter address and configuration links are preserved.

SEARCH THE LEFT PDF
Click Search in the Main text heading, or press Ctrl+F / Cmd+F. Type a word
or phrase. Use the arrows, Enter, or Shift+Enter to move through matches.
The selected match is orange; other matches are yellow. The right view
stays at its own reading position. Match case and Whole word are optional.
Close search to remove its highlights. Search marks are never saved into
the PDF. Search uses existing PDF text only; image-only scanned pages need
a searchable text layer made with OCR before word search can find them.
Search text and results stay in memory and are cleared when the PDF closes.

APPEARANCE
Use the Day / Night switch, or open Settings. The first visit follows your
device color theme. Settings offer teal, blue, violet, and amber palettes,
custom background and accent colors, and app text size from 14 to 24 px
(default 16 px). Smaller interface labels scale proportionally. These
choices affect the interface and comments, not PDF content or its zoom.
Custom colors are kept separately for day and night; foreground contrast
adjusts automatically. Preferences remain saved in this browser after the
PDF closes. Reset appearance restores the defaults.

READ AND NAVIGATE
Both PDF views scroll independently. Each has zoom-out and zoom-in buttons,
a zoom menu, and a hand tool. Select the hand and drag to pan horizontally
or vertically. Drag the dividers to resize the two views and notebook.

COMMENTS AND ANNOTATIONS
A notebook comment privately records the left-hand PDF page where you began
typing. View all comments opens the editable review in a popup. Export .txt
downloads all notebook comments plus any unfinished draft, without automatic
page markers. There is no inline list of comments beneath the notebook.

Each PDF toolbar offers Select, Hand, Highlight, Note, Circle/Ellipse,
Rectangle, Erase, Color, Undo, and Redo. Hover for labels. Marks appear in
both views. Undo and Redo share the annotation history across both views;
making a new change clears the redo list. Ctrl/Cmd+Z undoes and
Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y redoes when you are not editing text.

EXISTING PDF HIGHLIGHTS AND COMMENTS
Highlights and other annotations already embedded in an opened PDF appear
in both views. Choose Select, then click a small yellow comment icon to read
an existing note, a comment attached to a highlight, or a reply thread.
These imported comments are read-only here and remain in the PDF when you
save it. They are separate from your review notebook and TXT export.
Marks created with this app remain editable as before. Comments stored only
inside another app's own workspace must first be saved into the PDF.

SAVE PDF
Save PDF replaces Export PDF. In a browser supporting file access (such as
desktop Chrome or Edge), use Open PDF to select your original file. Save PDF
can write your annotations back to that file when you grant permission.
A PDF opened by drag and drop may need a save-location prompt. Other
browsers download a reviewed PDF copy. The status message reports whether
the app wrote to a file or sent a copy to downloads. Ctrl/Cmd+S also saves
the PDF when no dialog is open.

Saved PDFs contain native highlights, notes, circles and rectangles.
Annotations saved by Alpha 2 can be edited again in this app after reopening
the saved PDF. Original PDF annotations are preserved. Notebook comments
remain separate: use Export .txt to keep those. PDF export does not include
notebook comments or their automatic page metadata.

Saving password-protected PDFs is not supported. If another program changes
the selected PDF, reopen it before saving here. Failed or cancelled writes
leave your workspace open.

CLOSING, SWITCHING, AND RETURNING TO TOOLS
Opening another PDF, Close PDF, and the links back to Tools ask you to
confirm before erasing this workspace's comments, PDF notes, annotations,
and extracted references. Save PDF and export comments before confirming.
Cancelling keeps your current review. A file that fails validation does not
replace or erase the current review. Saved PDFs and TXT files stay on your
computer when the workspace closes.

For tab close, reload, or browser navigation, the browser shows its standard
leave warning when the review contains work. Its wording is chosen by the
browser. Browsers can suppress the warning, particularly on mobile. A normal
page-exit event clears this workspace; cancelling the warning does not.
Switching tabs does not erase the review. Browser autosave provides recovery
while a review is open. Browser crashes, force-closing, or blocked site storage
can prevent exit cleanup or recovery; export files to keep your work.

REFERENCES
Choose bibliography pages and extract locally. The Improved method uses
author-list patterns, numbering, and PDF indentation to keep wrapped lines
together, including continuations onto another page. Choose the citation
style (APA/Harvard author-year or IEEE/Vancouver numbered) and column layout
if automatic detection needs help. Enable manuscript line-number removal
when margin numbers enter the extracted text; it starts off by default.

If one citation is split, use Merge with previous on its extra entry.
You can also edit the extracted bibliography and rebuild the list, or choose
Original (v0.1) extraction. Extracting/rebuilding replaces manual merges.
Check the entries against the PDF: these are local format rules, not online
verification or a complete citation database. Local English OCR supports scans.
Optional Google links send the selected citation only when you open a link.

PRIVACY AND COUNTERS
PDF reading, annotation, and OCR run locally with bundled files. The app
does not upload PDFs, filenames, review notes, or references, and uses no AI
review or summary service. Privacy & help contains guidance only.

The counters are public on the Tools cards; the admin page only manages
resets. When configured, app opening sends its app ID and a random request
ID to the counter service. Bookmarks and reloads count too. These are page
opening totals, not unique-user counts; NESTApp counts its website visits.

Browser API details:
https://developer.mozilla.org/en-US/docs/Web/API/Window/showOpenFilePicker
https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event
