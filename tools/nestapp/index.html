What to expect

A guided interface around a configurable scientific workflow.

The application separates pipeline design from routine execution: an experienced user can configure and validate a workflow, save it, and reuse the same ordered steps and parameters across files or collaborators.

Point-and-clickChoose, order, and configure processing modules without writing the workflow from scratch.
Batch-readyApply one saved pipeline across multiple compatible EEG files with visible progress.
ReviewableInspect reports, processing history, TEP waveforms, topographies, and exported peak data.

Typical workflow

From raw recordings to an auditable output.

Users remain in control of the scientific decisions while NESTApp organizes the sequence, execution, and reporting.

  1. 01

    Start with a template—or an empty pipeline

    Load a ready-made workflow or select modules from the Cleaning tab. Add, remove, reorder, and configure each step and its parameters.

  2. 02

    Select data and run

    Choose one or more .set, .vhdr, .cnt, or .cdt files. The progress display follows the current file and processing step.

  3. 03

    Review quality and provenance

    Inspect per-file summaries for channels, retained trials, and ICA statistics. The complete pipeline, parameters, template citation, and timestamp remain in the processing history.

  4. 04

    Visualize and export

    Review TMS-evoked potentials and topographies, inspect canonical TEP components, export figures, and create long-format peak tables for downstream analysis.

Inside the application

The main capabilities users will encounter.

Pipeline builder

Ordered, editable modules

Select a processing step to see its purpose and parameters, then place it wherever it belongs in the pipeline.

Reusable setup

Save and reload pipelines

Store the selected steps and settings as a MATLAB file, restore them later, and access recent pipelines from the application.

Templates

Published workflows as starting points

Begin from TESA, ARTIST, AARATEP, resting-state, or minimal-processing templates and adapt them to the study.

Quality review

Reports after every run

Browse subject-level summaries, copy a methods-ready description, and export batch summaries to CSV.

Visualization

TEPs and scalp topographies

Choose an electrode region of interest, overlay datasets, identify canonical TEP components, and inspect spatial patterns.

Analysis export

Peaks ready for statistics

Export component latency and amplitude in a long-format table with trial counts, search windows, and ROI channels.

Included starting points

Pipeline templates

Templates make established processing strategies easier to load and inspect. They are starting points, not substitutes for study-specific validation.

Scientific responsibility

Automation does not choose the right pipeline for you.

NESTApp helps execute and document a workflow consistently. Researchers should still justify their processing choices, inspect intermediate and final signals, verify dependency versions, and cite both NESTApp and the methods underlying any template they use.
