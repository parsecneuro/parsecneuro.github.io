Template asset notice
=====================

The file:

  assets/fsaverage_scalp_mesh.js

contains vertex and triangle arrays converted from the MNE-Python 1.11.0
asset:

  mne/data/fsaverage/fsaverage-head.fif

The conversion changed the storage format for browser use and converted
coordinates from meters to millimeters. It did not create a participant-
specific anatomical model.

The default coordinate file was generated from MNE-Python's standard_1005
montage and filtered to the conventional 10-10 labels included in this release.
